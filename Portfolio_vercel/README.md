# Mark Bryan Delos Santos — CV & Portfolio

A responsive, editorial-style CV and student portfolio for Mark Bryan Delos Santos, an IT College Student at DNSC. A hand-built collage hero, custom academic ledger, student project timeline, staggered skills atlas, interactive project galleries, code-window feature, certificate gallery, and animated pull-cord light switch give each section its own visual rhythm while keeping the full CV easy to navigate. The AgriSync mobile app and its promotional website are presented as separate projects. The light and dark themes are coordinated across the page, remembered between visits, and respect reduced-motion preferences.

## Technologies

- Semantic HTML
- Responsive CSS with section-specific motion, kinetic type, timeline transitions, orbit effects, and reduced-motion support
- Vanilla JavaScript for navigation, section reveals, reading progress, and persistent light/dark theme switching
- Local editorial portrait collage and certificate scans
- Food Ordering Management System (Java, JFrame, SQL)
- Coffee Shop Website (HTML, CSS, JavaScript)
- TinkerNest mobile platform (Flutter, Dart, Supabase)
- AgriSync mobile app (Flutter, Dart, Supabase) with locally bundled app-screen previews
- AgriSync promotional website (HTML, CSS, JavaScript) with locally bundled previews and live link: https://agrisync-blush.vercel.app/
- Google Fonts: Manrope and DM Mono
